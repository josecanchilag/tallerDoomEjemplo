# Práctica DOM con JavaScript

Diez ejercicios de manipulación del DOM con HTML, CSS y JavaScript puro (sin librerías).

## Estructura
```
practica-dom/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── js/
    ├── 01-cambiar-titulo.js
    ├── 02-cambiar-color.js
    ├── 03-mostrar-ocultar.js
    ├── 04-crear-elementos.js
    ├── 05-eliminar-elementos.js
    ├── 06-lista-desde-array.js
    ├── 07-tarjetas-desde-objetos.js
    ├── 08-formulario.js
    ├── 09-lista-tareas.js
    └── 10-crud-estudiantes.js
```

## Cómo ejecutar
Abre `index.html` en el navegador. No requiere instalación.

## Ejercicios
1. Cambiar un título con un botón
2. Cambiar el color de un texto
3. Mostrar / ocultar un elemento
4. Crear elementos dinámicamente
5. Eliminar elementos
6. Crear una lista a partir de un array
7. Crear tarjetas a partir de objetos
8. Crear un formulario y mostrar sus datos
9. Crear una lista de tareas
10. CRUD completo de estudiantes (guarda los datos en localStorage)
